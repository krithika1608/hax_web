# Twinkle — The Lost Star Collector ✦
Keep `index.html` and `assets/` together. Open `index.html`, or upload both to a GitHub repo root and enable Pages (Settings → Pages → main / root).

- **Voice:** `assets/twinkle-story.mp3` plays only when you tap "Tell me your story" (or ask about her story) in the chat. Other replies are read aloud (🗣) or use phrases from `twinkle-voice.mp3` (🎙).
- **Chat:** ask about her story, favourites, jokes, wishes, hugs, games, or tell her you're sad.
- **Games:** Star Archive, Glow Workshop, Sky Map, Star Catcher.
